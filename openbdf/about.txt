OpenBDF – Open Building Data Format
Version 2.0.0 | October 2026 | pre-validation

OpenBDF is pre-existing intellectual property of the Global Building Data
Initiative (GBDI) at EPFL. It remains the property of GBDI.

This version is shared for expert review ahead of the November 2026 workshops
and is not yet validated. Any licence to use it is non-exclusive and limited to
the purpose for which it was shared. Material changes to the specification are
to be agreed with GBDI before they are made, so that the format is not split before it is consolidated.

Author: Dr Eng. Nicole Di Santo, Technical Lead, GBDI, LMC, EPFL, Lausanne.
Parser and code implementation: ENAC-IT4R, EPFL, Lausanne
Code repository: https://github.com/EPFL-ENAC/lmc-openbdf/
